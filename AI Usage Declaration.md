**Declaration:** In compliance with the course's AI Usage Guidelines, our group declares the use of Generative AI tools to support specific tasks during the project "Data Structure Visualization".

### 1. General Tool Information & Development Strategy

* **Tool Names:** Google Gemini, Anthropic Claude, GitHub Copilot.
* **Access Period:** March & April 2026.
* **Backend Development Strategy:** The core algorithmic logic, data structures, and state management backend were hand-coded by the team. AI tools were strictly utilized in a limited capacity for code review, debugging assistance, and generating suggestions on how to synchronize backend logic with the frontend interface.
* **Frontend Development Strategy ("Vibe Coding"):** The team heavily utilized AI to assist in "vibe coding" the User Interface. In this context, AI was used to help implement and refine aesthetic rendering, user action handling, complex step-by-step animations, state synchronization, and keyboard shortcut logic across the application.
